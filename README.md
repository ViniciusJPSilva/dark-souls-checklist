# Dark Souls Remastered — Checklist de Troféus (PT-BR)

Checklist dos 41 troféus/conquistas de **Dark Souls Remastered**, com os nomes da tradução oficial em português, imagens dos itens e progresso salvo no navegador.

- Feitiços, piromancias, milagres e armas raras com imagem, custo, NPC, local, requisitos e observações
- Troféus de coleção e a platina são marcados automaticamente
- Busca sem acentos, filtro *Todos / Pendentes / Feitos*, nomes em inglês opcionais
- Exportar/importar progresso por código (para levar a outro aparelho)
- Mobile first, sem build: HTML + CSS + JavaScript (ES modules)

## Rodar localmente

Como usa ES modules, abrir o `index.html` direto (`file://`) não funciona. Use um servidor estático:

```bash
npx serve .
# ou
python -m http.server 8000
```

## Créditos

Nomes dos troféus: lista oficial PT-BR (PSN/Xbox/Steam). Nomes de magias, armas, áreas e NPCs: tradução PT-BR do jogo, conferida com a [Estus](https://estus.com.br/wiki/dark-souls). Imagens: [Fextralife](https://darksouls.wiki.fextralife.com) e PSNProfiles. Dark Souls é marca da FromSoftware/Bandai Namco; projeto de fã sem fins lucrativos.
